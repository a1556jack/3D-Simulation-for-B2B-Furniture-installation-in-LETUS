# 반입 조건 기록과 검토

`반입 조건` 탭에서 25종의 현장·장비·적재물 항목을 기록합니다. 각 기록은 값, 단위, 출처, 확인일, 확인 방법과 이 기기에서의 검토 이력을 가집니다. 새 기록과 가져온 기록은 검토 대기이며, 담당자가 출처·날짜를 확인하고 `확인하여 사용`을 눌러야 비교에 사용됩니다. 계정 기반 승인이나 팀 서버 동기화는 아닙니다.

- 램프: 유효 폭·높이·경사.
- 주차장: 유효 높이.
- 하차 공간: 유효 폭·길이.
- E/V: 문 폭, 내부 폭·깊이·높이, 정격하중, 운행층, 이용조건·위치.
- 차량: 실제 높이·폭·길이. 11톤이라는 분류에서 제원을 만들지 않습니다.
- 지게차: 마스트 하강 높이, 전폭·전장, 자중, 정격인양하중. 자중과 인양하중을 분리합니다.
- 적재물: 최대 폭·길이·높이·무게. 가구 상품 카탈로그를 만들지 않습니다.

현재 비교는 선택한 실제 차량 제원에 대한 램프 직선 구간 높이·폭, 주차장 높이 3개 항목입니다. mm/m, t/kg은 명시된 단위에 따라 변환됩니다. 여유 치수는 사용자가 직접 입력하며, 빈 값을 0으로 바꾸지 않습니다. 확인된 치수 초과는 실패로 표시하고, 미확인 정보는 정보 부족으로 표시합니다.

전체 경로의 회전, 램프 전환부, 윙 개방, 테일리프트, 지게차 하역, 바닥 구조 및 전도 안정성 검사는 구현되지 않았습니다. E/V 탑승은 자동 판정에서 제외합니다. 개별 비교가 충족돼도 전체 반입을 통과로 표시하지 않습니다. 6대의 실제 차량 제원이 다르면 각각 검토해야 합니다.

## 기록 저장과 가져오기

하단 `기록 저장`은 현재 브라우저에 저장합니다. `기록 내려받기`는 출처별 기록·선택 상태·여유 설정·메모·지도 동선을 JSON으로 내보냅니다. `기록 파일 가져오기`는 같은 현장의 출처별 기록만 병합합니다. 다른 현장 ID는 거부하며, 가져온 파일의 선택 상태·여유 설정·검토 완료 상태는 자동 적용하지 않습니다. 기존에 선택한 실측값은 그대로 유지됩니다.

같은 ID와 같은 내용은 중복으로 제외합니다. 같은 ID의 다른 내용은 충돌로 알리고 기존 값을 유지합니다. 새 ID로 들어온 다른 관측값은 검토 대기 목록에 추가됩니다. 최대 500개 기록과 8MB 파일을 지원합니다. 공개 정보의 갱신을 실측값에 덮어쓰는 기능은 없습니다.

이전 버전의 출처 없는 간단 입력은 JSON의 `legacyObservations`에 보존하며, 자동으로 확인된 측정값으로 승격하지 않습니다. 원본 파일과 브라우저 기록을 보관하세요.

## 현재 데이터 연결 상태

실제 지역 지도는 OpenStreetMap/Protomaps 원본에 연결되어 있습니다. 램프·주차장·승강기 공식 API 연결, 남평로 111-73의 정확한 동·반입구 식별, 실제 장비 모델 제원은 아직 미확보입니다. 현장 기록과 공공 지도 윤곽을 주소 유사성만으로 연결하지 않습니다. 공개 API의 사용 승인·인증키 및 해당 목적지 접근, 현장별 확인 자료가 확보되어야 실제 현장 판정으로 진행할 수 있습니다.

파일을 읽는 동안 기록 입력을 잠시 잠그며, 패널을 떠나면 아직 적용되지 않은 읽기를 취소합니다. 손상되었거나 다른 현장에 속한 기존 저장 기록은 현재 현장에 적용하지 않습니다. 새 기록을 저장하기 전에 원본 복구 사본을 먼저 보존하며, `복구 원본 내려받기`로 받을 수 있습니다. 사본을 만들 저장 공간이 없으면 원본을 덮어쓰지 않습니다.
