# 반입 후보 검사·추천 사용법

이번 버전은 사용자가 지정하고 자료를 확인한 **차량 경로, 반입 장비 경로, 하차 공간 후보**를 검사한다. 같은 현장에서 후보를 비교할 수 있고, 검사 결과에 따라 3D 지도에 경로·위험 위치·차량 외형을 표시한다. 공공지도에서 자동으로 도로망을 생성하거나 빈 공간을 하차 가능 구역으로 확정하는 기능은 아니다.

## 실제 현장 사용 순서

1. `반입 계획 → 현장·파일`에서 작업 동·반입구, 출처·확인일, 관리자 여유 치수를 입력한다. 좌우 여유는 **각 방향에 적용하는 값**이며, 기존 `반입 조건`의 전체 폭 여유와 다르다. 차량은 1~20대에서 선택하며, 기본값은 11톤 윙바디 6대와 3톤 지게차다. 기본 작업 방식은 1대씩 순차 반입이다.
2. `장비`에서 차량 대수와 하역 장비(지게차/사다리차/기타)를 선택하고 차량마다 톤수·차종(윙바디/탑차/카고)·실제 제원을 입력한다. 동일 제원 복사는 가능하지만 다른 차량의 확인은 해제되어 각 차량의 실제 상태를 다시 확인해야 한다. 지게차는 정격하중과 자중, 최대 적재물 외형·무게를 별도로 기록한다.
3. `경로`에서 차량 접근 경로와 선택 장비의 반입 경로를 추가한다. 지도 클릭 또는 기준점에서 동·북 방향의 미터 좌표로 지점을 지정한다. 지도 도로에 자동으로 맞춰지지 않는다. 구간별 유효 폭·높이·경사, 전진/후진, 출처를 기록하고 경로 위치·통행 허용·장애물 조사 여부를 확인한다.
4. `하차 공간`에서 후보 중심과 직사각형 유효 공간, 상부 높이, 방향, 좌측 윙 하역/후면 리프트 하역 방식을 지정한다. 차량 접근 경로 종점과 장비 작업 지점을 연결한다. 지게차는 경로 시작점, 사다리차는 접근 경로 종점이 작업 지점이다. 하역 공간은 실제 정차 위치와 차체 방향에 맞아야 한다.
5. `장애물`에서 벽·기둥·배관의 유효 외형과 하단·상단 높이를 기록한다. 높이는 해당 위치 노면 기준이다. 지도 건물 높이에서 자동으로 실측값을 가져오지 않는다.
6. `결과`에서 각 후보의 통과/초과/정보 부족과 이유를 확인한다. 위험 항목에서 지도를 해당 위치로 이동할 수 있다. 선택 후보에서 차량·장비 이동 외형을 재생한다.
7. `현재 조건으로 작업서 발행`으로 선택한 후보와 조건을 고정한다. 작업서 인쇄 화면에서 PDF로 저장하거나 독립 HTML 작업서를 내려받는다. 조건 변경 시 이전 작업서는 재검토 상태가 되고 인쇄 버튼이 비활성화된다. 과거 기록을 내려받으면 현장 사용 중지·재발행 필요 표시가 파일에 포함된다. `기록 저장`은 실제 현장 계획과 작업서 이력을 현재 브라우저에 저장한다.

`합성 예제로 기능 확인`은 별도 메모리 상태에 있으며 실제 현장 계획을 덮어쓰지 않는다. 예제는 실측 현장·제조사 카탈로그가 아니고 현장 작업에 사용하면 안 된다. 예제 모드임을 패널·지도·작업서에 표시한다.

## 판정과 추천

- 실패가 하나라도 있으면 해당 후보는 실패다. 실패가 없지만 필수 정보가 빠지거나 자료 확인이 없으면 정보 부족이다.
- 모든 적용 검사와 현장·공간 확인을 충족한 후보만 조건상 추천할 수 있다. 통과 후보끼리는 차량·장비 총 동선 길이, 정렬 배치 가능 대수 순으로 비교한다. 정보 부족 후보는 추천으로 표시하지 않는다.
- 선택한 모든 차량을 같은 접근 경로에 대입한다. 각 차량의 정차 외형과 장비 경로 간섭도 확인한다. 3D 재생은 대표 1호 차량을 표시하며 선택한 모든 차량의 검사 결과는 모두 목록에 포함된다.
- 하차 공간 대수는 동일한 보수적 작업 외형을 정렬 배치한 면적 검토다. 2대 이상 동시 정차는 차량별 자리의 개별 접근·퇴출 경로가 아직 없으므로 전체 통과로 추천하지 않는다. 전체 차량의 1대씩 순차 하역은 각 장비 조건을 적용해 검사한다.
- 기존 `반입 조건` 탭은 현장 전체의 단일 차량 치수 비교 기록이다. 새 경로 구간으로 자동 승격하지 않는다. 개요와 JSON에는 해당 비교 결과 및 새 계획 결과를 구분해 싣는다.

## 기하학 모델과 한계

- 길이는 m, 하중 기록은 kg, 경사는 진행방향 %, 평면 방향은 동쪽 0°·북쪽 90°다. 단면은 수직이고 횡단 경사·노면 비틀림은 모델링하지 않는다.
- 차량은 전륜 조향의 뒤 축, 지게차는 후륜 조향의 앞 축을 비조향 기준축으로 사용한다. 입력 회전반경도 그 축 중심 기준이어야 한다. 제조사의 바깥 차체 회전반경이나 최소 회전 통로 폭을 그대로 넣으면 안 된다.
- 차량 전장과 축간거리+앞/뒤 오버행의 합이 맞는지 확인한다. 5cm는 입력 일치 확인 허용차이며 통과 여유가 아니다.
- 경로 모서리에 지정 반경의 원호를 넣는다. 직선이 짧아 원호가 겹치거나 장비 최소 반경보다 작으면 초과다. 조향 속도, 하중에 따른 타이어 변형, 다축 특수 조향, 트레일러는 모델 밖이다.
- 직선은 시작·끝 외형의 연속 이동 영역을 검사하므로 중간의 얇은 장애물을 건너뛰지 않는다. 원호는 최대 2.5° 구간으로 나누고 회전 반경에 따른 오차 범위를 추가한다. 외형이 직접 겹치면 초과, 추가 오차 영역에서만 겹치면 정보 부족이다.
- 회전 통로 폭은 곡선 중심선 주변의 필요한 대칭 폭으로 보수적으로 검사한다. 구간별 실측 폭이 직선 벽 간 거리만을 뜻한다면 코너 공간을 별도로 조사해야 한다.
- 램프는 평면 바닥과 평면 하부를 가정해 경사 전환각을 지상고·축간거리·오버행 한계와 비교한다. 지게차는 운반 높이도 하부 여유에 반영한다. 경사에 따른 외형 높이 증가와 차체 상단의 수평 돌출을 모두 보수적으로 반영한다. 하차 영역은 경사 0%가 확인된 수평 노면으로 한정한다. 실제 차대·범퍼·서스펜션·포크 형상을 정밀 복원한 검사가 아니다.
- 윙/리프트는 입력한 추가 폭·높이·길이와 지게차 작업 통로를 직사각형 작업 영역으로 비교한다. 힌지·유압 장치의 개별 운동 모델이나 동적 하역 절차 시뮬레이션은 아니다. 도크 단차의 실제 연결은 별도 확인 항목이다.
- 바닥 구조 안전, 지게차 전도 안정성, 실제 인양능력은 자동 판정하지 않는다. E/V 앞 또는 장비 작업 종점에서 경로를 끝낸다. E/V 탑승은 자동 통과 판정에 포함하지 않는다.

## 파일·보존

계획 파일은 버전 2(버전 1 자동 변환), 최대 2MB, 차량 1~20대/하역 장비 1대, 경로 8개(각 24지점), 하차 후보 8개, 장애물 24개까지다. 숫자 범위, ID 중복, 좌표, 날짜, 현장 ID를 검증한다. 가져온 확인 상태는 해제하며 현재 기기에서 다시 확인한다. 읽는 동안 계획이 변경되면 가져오기를 취소한다.

잘못된 저장 기록을 읽었을 때 원본을 유지한다. 새 저장 전에 별도 복구 사본을 만들며, 복구 사본 쓰기에 실패하면 원본을 덮어쓰지 않는다. 작업서와 계획은 브라우저 저장이며 서버 공유·초대 계정·사진 오프라인 동기화를 제공하는 것은 아니다.

## 차량·장비 선택과 사다리차

차량 수를 줄여 숨긴 제원은 보관하며 대수를 늘리면 복원한다. 지게차↔사다리차↔기타 장비 전환도 종류별 제원을 보관한다. 장비 종류가 바뀌면 연결 경로와 하차 공간의 확인 상태를 해제한다. 각 숫자·차종·조향·작업 조건 변경 시 장비 출처 확인도 해제한다. 기존 작업서는 조건 변경 상태가 된다.

톤급은 구분용이다. 톤급·차종으로 외형을 생성하거나 실제 인양능력을 보장하지 않는다. 카고·탑차의 측면 하역은 실제 측면 개방 가능 여부를 명시해야 한다. 윙 차량만 윙 추가 폭·높이를 요구하며, 뒤 리프트가 없으면 전개 길이에 0을 입력한다.

사다리차는 실제 외형을 사용한 접근 경로 검사, 종점의 차체·아웃트리거 설치 영역, 정차 차량과 하역 통로의 간섭을 검사한다. 아웃트리거 중심은 비조향 기준축에서 차체 앞 방향 오프셋으로 입력한다. 지도에는 차체와 보라색 설치 영역을 표시한다. 목표 높이·필요 수평 거리·적재 무게를 입력하고 실제 모델의 제조사 작업표에서 **해당 조합**이 허용되는지 확인해야 한다. 최대 높이와 최대 수평 거리를 각각 만족하는 것만으로 추천하지 않는다. 사다리 전개 방향과 건물·전선·수목 등 상공 장애물은 하차 후보별 현장 확인 항목이다. 설치 위치·방향·장비·장애물이 바뀌면 기존 상공 확인은 무효가 된다. 목표 높이·거리·하중·모델 등 제원 변경 시 제조사 작업표 조합 확인도 해제한다. 층수에서 작업 높이를 자동 추정하지 않으며, 붐의 연속 전개 궤적·지지력·전도 안정성을 자동 계산하지 않는다.

기타 장비는 접근 외형과 제원을 기록하지만 장비별 작동 검토가 미구현이므로 전체 판정은 정보 부족으로 남는다.
