# 구현 범위와 남은 현장 검증

현재 실행본에는 지역 건물 윤곽 3D 외에 반입 계획 편집, 차량 6대·지게차 개별 제원, 구간 조건과 장애물, 하차 후보 비교, 보수적인 이동 외형 검사, 3D 재생, 고정 조건 작업서(HTML·브라우저 PDF 인쇄)가 있다. [사용법·계산 모델](PLANNER.md).

반입로 추천은 **사용자가 지정한 경로와 하차 공간 후보의 비교**다. 통과 후보만 추천하고, 통과끼리는 총 동선이 짧은 후보를 우선한다. 지도 도로망 자동 탐색, 빈 땅의 사용 권한 판단, 실제 반입구 자동 확정은 구현하지 않았다. 두 대 이상 동시 정차는 정렬 배치 가능 대수를 제공하지만 자리별 접근·퇴출 경로가 없으므로 전체 통과로 추천하지 않는다. 하역 영역은 수평 노면 모델이고 경사지 하역은 정보 부족으로 남긴다.

실제 용인 현장의 판정에 필요한 자료:

- 남평로 111-73의 정확한 건물·작업 동·반입구 식별. 초기 지도 핀은 남평로 주변이다.
- 구간별 램프 폭·높이·경사·전환부, 주차장 상부 장애물, 사용 가능한 하차 공간과 관리사무소의 운영조건.
- 차량 6대의 실제 모델·특장·외형·축간거리·오버행·기준축 회전반경, 지게차 모델·마스트·포크·적재 상태 제원.
- E/V 위치·문/내부 치수·운행층·이용조건. 자동 경로 판정은 E/V 앞 또는 장비 작업 종점까지다.
- 공공정보 공급자의 실제 승인·인증과 도메인 접근. 현재 실행 환경 revision 2의 인증 설정은 비어 있다. 환경 설정 초안 저장은 활성화·API 이용승인을 의미하지 않는다.

추가 구현 범위에는 도크 연결부와 차량의 정밀 차대/가동부 모델, 다축 특수 조향, 동시 정차 자리별 이동 경로, 초대 계정·작업 배정·팀 서버 공유, 사진과 IndexedDB 오프라인 기록 동기화가 있다. 현재 저장은 브라우저의 로컬 기록이다.

바닥 구조 안전, 지게차 전도 안정성, 실제 인양능력, E/V 탑승은 자동 통과 판정에서 제외한다. 기록한 톤급·정격하중만으로 이를 승인하지 않는다. 확인되지 않은 현장을 예제나 지도 가정 높이로 채워 통과시키지 않는다.
